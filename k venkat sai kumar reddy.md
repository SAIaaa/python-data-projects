# API Data Retrieval and Processing Project

## Features
- Fetches book data from REST API and stores in SQLite
- Fetches student scores, calculates average, visualizes using bar chart
- Imports CSV user data into SQLite database

## Technologies Used
- Python
- SQLite
- REST API
- Matplotlib

## How to Run
```bash
pip install -r requirements.txt
python books_api_to_db.py
python student_scores_visualization.py
python csv_to_sqlite.py
